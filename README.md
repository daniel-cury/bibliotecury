# bibliotecury

Minha biblioteca pessoal: os livros que já li, com um resumo e o que achei de cada um.

Site: https://daniel-cury.github.io/bibliotecury/

## Como adicionar um livro

Edite [`livros.js`](livros.js): copie um bloco `{ ... }`, preencha os campos e faça commit/push.
O GitHub Pages atualiza o site sozinho em cerca de um minuto.

Para ver localmente: `python3 -m http.server` nesta pasta e abra http://localhost:8000.
